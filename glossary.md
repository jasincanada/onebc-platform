# Short forms

[The day](README.md) · [Features](features.md) · [Engineering](engineering.md) · [The rules](compliance.md) · **Glossary** · [Comment on this page](https://github.com/jasincanada/onebc-platform/discussions/6)

On the other pages, a short form has a dotted underline. On a computer, rest on it and the meaning appears. On a phone, use this page.

| Short form | Meaning |
|---|---|
| a.m. | Before noon. |
| B.C. | British Columbia. Also written BC. |
| CRTC | The Canadian Radio-television and Telecommunications Commission. The federal body that sets the rules for phone calls in Canada. |
| GST | The federal goods and services tax. It is not included in the fee, and it is not added to it. |
| Node | Short for Node.js. The program that runs the desk on the server. |
| OneBC | The party this briefing is written for. The name is OneBC. |
| p.m. | After noon. |
| Postgres | Short for PostgreSQL. The database that holds the list, the notes, and the removal list. |
| PST | The British Columbia sales tax. It is 7% when a sale is taxable. It is not included in the fee. |
| VoIP | A phone call carried over the internet. On these pages it appears in the name VoIP.ms, the Canadian phone company. |

These are the only short forms on the site. A company name that is not a short form, such as Telnyx or Cloudflare, is not listed here.
